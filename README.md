# 💸 Yudiahorro

Panel de finanzas del hogar: ingresos, gastos, presupuesto, pagos fijos y suscripciones, calendario de pagos, rifas, inversiones, metas de ahorro, fondo de emergencia y deudas/sanes.

🔐 **Privacidad:** este repositorio no contiene datos personales. Todo lo que anotes se guarda **solo en tu navegador** (localStorage). Para usarlo en varios teléfonos/PC, activa *Ajustes → Sincronización* con un código familiar: los datos se cifran en tu dispositivo (AES-GCM, clave derivada con PBKDF2) antes de subirse, y el servidor solo guarda texto cifrado. *Ajustes → Descargar respaldo* sigue disponible.

Hecho con HTML, CSS y JavaScript puro + Chart.js. Sin servidor, sin build.
